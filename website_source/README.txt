Загрузка на сервер Hestia:

1. Открой File Manager.
2. Перейди в:
   /home/ODESSA/web/glukotrack.com/public_html/
3. Удали старый index.html.
4. Загрузи все файлы из этого архива в public_html:
   index.html
   style.css
   app/
   video/
   images/
5. Открой https://glukotrack.com

Для Flutter Web:
- Выполни flutter build web
- Загрузи содержимое build/web/ в:
  /home/ODESSA/web/glukotrack.com/public_html/app/
