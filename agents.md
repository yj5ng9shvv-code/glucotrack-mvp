Работать только внутри активного эталонного проекта GlucoTrack.
- Не искать по всему диску.
- Не брать старые бэкапы.
- Никакой подмены фронтенда.
- Запрет на изменение текущей зафиксированной верстки без прямого задания.
- Не трогать кодировки.
- Не ломать локализации.
- Весь текст только через i18n ключи при добавлении переводов — все тридцать языков.
- Не менять базу данных.
- Не менять порты.
- Не менять env/out без прямой задачи.
- Не использовать никакие непонятные базы, только то, что подключено в активном env.
- Запрет на разрушительные действия без отдельного разрешения:
  - удаление файлов;
  - drop таблиц;
  - truncate таблиц.
- Всегда перед работой показывать:
  - рабочую папку;
  - git branch;
  - пути frontend;
  - пути backend;
  - пути build;
  - пути prod.

После любой задачи обязателен отчет:

- измененные файлы;
- выполненные команды;
- доказательства проверки результата.

Если что-то не ясно — остановиться и задать вопрос.
